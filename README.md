# 2️⃣ Caesar Cipher Encryption 🔒

A basic encryption and decryption system built using Caesar Cipher logic.

## Features

* Encrypt text
* Decrypt text
* Custom shift key
* Supports uppercase/lowercase letters
* Encryption formula implementation

## Technologies Used

* Python

## Run Project

```bash
python Project2.py
```

## Encryption Formula

Encryption:
E(x) = (x + n) % 26

Decryption:
D(x) = (x - n) % 26
